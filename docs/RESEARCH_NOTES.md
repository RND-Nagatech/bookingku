# Research Notes

## Studio Foto
Referensi NALA Studio: microsite publik menampilkan value proposition, paket, weekday/weekend, add-ons, jumlah orang, ringkasan sesi, review, lokasi, dan CTA booking. BookingKu mengambil pola informasi dan UX tersebut tanpa menyalin branding/layout 1:1.

## Salon / Barbershop
Referensi customer journey Fresha/Booksy: service selection, optional professional, realtime availability, review details, optional upfront payment, reminders/rebooking/waitlist. MVP BookingKu mengimplementasikan core journey service -> staff -> date/time -> customer -> confirmation.

## Lapangan Olahraga
Referensi Playtomic/Bookteq: sport/facility -> date/time -> court/facility -> duration -> review/payment. MVP BookingKu mengimplementasikan sport -> court -> duration -> live slot -> customer -> confirmation.
